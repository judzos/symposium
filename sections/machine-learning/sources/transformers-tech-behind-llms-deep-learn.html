Transformers, the tech behind LLMs | Deep Learning Chapter 5

GPT-3’s 175 billion weights are organised into just under 28,000 matrices falling into 8 categories, and this chapter accounts for the first billion of them exactly — the embedding and unembedding matrices — establishing that a token’s vector does not stay a word: it is a position in a 12,288-dimensional space that later blocks tug into encoding an entire context.

Key Concepts

  • The name decomposed — Generative (it generates text), Pre-trained (trained on large amounts of data), Transformer (the part that matters). Transformers underlie voice-to-text, text-to-voice, text-to-image and translation; the GPT variant predicts a probability distribution over what text follows.
  • Tokens are not words, and the example proves it — “To date, the cleverest thinker of all time was” tokenises as To| date|,| the| cle|ve|rest| thinker| of| all| time| was. Sanderson then pretends tokens are words for the rest of the chapter, saying so explicitly.
  • The high-level circuit — tokens → embedding vectors → attention block (vectors communicate and update from context: model in “a machine learning model” vs. “a fashion model”) → multilayer perceptron / feed-forward layer (no communication; every vector goes through the same operation in parallel) → attention → MLP → … “A large number of layers like this is what puts the ‘deep’ in deep learning.” Only the last vector goes through the final computation.
  • Two conventions that make the rest readable — weights are drawn blue/red and the data being processed grey, because “the weights are the actual brains of the model”; and everything is a matrix-vector product rather than an explicit weighted sum, with non-linearities sprinkled between to stop the whole model collapsing to linear.
  • Scale is not automatically good — GPT-3 has 175 billion parameters, but “simply giving a model a huge number of parameters does not guarantee that it will perform better. Models at such scales risk being either completely intractable to train, prone to overfitting, or both.”
  • Embedding: 617,558,016 weights, counted — vocabulary 50,257 columns × embedding dimension 12,288. Each column is what one token becomes in step one; values start random and are learned.
  • Directions in embedding space acquire meaning — nearest neighbours of tower share a “vibe”; woman − man ≈ king − queen. Sanderson immediately qualifies the classic example: in the model he used, queen is farther off than the difference suggests, “presumably because the way queen is used in training data is not merely a feminine version of a king,” and family relations illustrate it better. Another: Italy − Germany + Hitler lands near Mussolini, as if some directions encode Italian-ness and others Axis leadership.
  • The dot product as a measurable test of a direction — positive when vectors align, zero when perpendicular, negative when opposed. Take cats − cat as a candidate “plurality direction”: dotting it against nouns gives consistently higher values for plurals, and against one, two, three, four gives increasing values, “as if it’s quantitatively measuring how plural the model finds a given word.”
  • A vector’s job is to stop being a word — the initial lookup encodes one token with no input from surroundings; the network’s primary goal is to let each vector “soak up meaning that is more rich and specific than what mere individual words can represent.” A vector that began as king can end up encoding a king who lived in Scotland, who took the post by murdering his predecessor, described in Shakespearean language.
  • Context size, and why early ChatGPT lost the thread — GPT-3’s context was 2048 tokens, so the data is a 2048-column array of ~12k-dimensional vectors. That limit is the direct cause of long conversations feeling as if the bot lost its place.
  • Unembedding: another ~617M weights — W_U maps the last vector to ~50,000 values, one per token, with rows and columns swapped relative to W_E. Running total: a little over a billion of the eventual 175 billion. Using only the last vector looks wasteful, and the reason is training efficiency: every vector in the final layer simultaneously predicts what follows it.
  • Softmax and temperature, precisely — raise e to each value, sum, divide. It is called softmax because rather than pulling out the biggest value it gives weight to all relatively large values in proportion. Inserting a constant T into the exponents: larger T gives more weight to lower values and a more uniform distribution; smaller T lets large values dominate; at T = 0 all weight goes to the maximum. The raw unnormalised inputs are the logits.
