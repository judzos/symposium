Embedding

An embedding is a token’s vector and the space it inhabits, where directions carry meaning. A transformer expresses each operation as an edit to positions in this space.

flowchart LR
  T[Token] --> WE[W_E lookup — one column per vocabulary item]
  WE --> V[A vector encoding that token and nothing else]
  P[Position, encoded in the same vector] --> V
  V --> A[Attention and MLP blocks edit the position]
  A --> C[A vector that has soaked up the surrounding context]
  C --> WU[W_U unembedding — one value per vocabulary token]
  WU --> L[Logits]
  L --> S[Softmax — a distribution over next tokens]
  CS[Context size — the attention pattern is its square] -->|a hard ceiling| A

Training operates on continuous values, so models must encode language as numbers. The learned encoding develops a legible geometry.

The lookup table is only the starting point

The first matrix, W_E, has one column per vocabulary item. In GPT-3, that means 50,257 columns × 12,288 dimensions = 617,558,016 weights. At that moment a vector encodes one token and nothing else: “effectively a lookup table with no input from the surroundings.”

The network then enriches that vector with context. transformers-tech-behind-llms-deep-learn frames this as the primary goal: let each vector “soak up meaning that is more rich and specific than what mere individual words can represent.” A vector that began as king can end up encoding a king who lived in Scotland, who took the throne by murdering his predecessor, described in Shakespearean language.

attention-transformers-step-by-step-deep illustrates the requirement with a mystery novel ending “Therefore the murderer was…” The final vector, which started life embedding was, must absorb everything in the context relevant to the answer because it is the only vector used for the prediction.

What is a token's vector at the moment it leaves the embedding matrix?

A lookup with no input from its surroundings — it encodes that token and nothing else. Everything that follows exists to make that stop being true.

Why must the last vector in a mystery novel carry the whole plot?

Because it is the only vector used for the prediction. A vector that started life embedding “was” has to have absorbed everything in the context relevant to naming the murderer.

Directions have meaning, and the dot product tests them

  • Nearest neighbours of tower share a recognisable character.
  • woman − man ≈ king − queen. Sanderson qualifies the classic example: in the model he used, queen sits farther off than the difference predicts, “presumably because the way queen is used in training data is not merely a feminine version of a king.” Family relations demonstrate it better.
  • Italy − Germany + Hitler lands near Mussolini. Some directions appear to encode Italian-ness, others Axis leadership.

Why does Sanderson qualify the king − man + woman ≈ queen example?

In the model he used, queen sits farther off than the difference predicts — presumably because queen is not used in training data as merely a feminine king. Family relations demonstrate the property more cleanly.

The dot product turns a hunch about a direction into a measurement: positive when aligned, zero when perpendicular, negative when opposed. Take cats − cat as a candidate plurality direction and dot it against nouns. Plurals score consistently higher, and one, two, three, four give increasing values, “as if it’s quantitatively measuring how plural the model finds a given word.”

How do you test whether a direction in embedding space means what you think?

Dot it against words you have opinions about. Take cats − cat as a candidate plurality direction and plurals score higher; one through four give increasing values, which is the direction measuring degree rather than just membership.

This is the machinery every later block reuses: attention-transformers-step-by-step-deep scores key–query alignment by dot product, and might-llms-store-facts-deep-learning reads MLP rows as directions whose dot product with a vector asks a question about it.

Position is in there too

Embeddings also encode where a token sits through positional-encoding, so a single vector’s entries tell you both what the word is and where it is in the context.

Context size is a hard ceiling

GPT-3’s context was 2048 tokens, so the data flowing through is a 2048-column array of ~12k-dimensional vectors. Sanderson attributes early ChatGPT’s tendency to lose the thread in long conversations to that limit. Enlarging it is nontrivial because the attention pattern is the square of the context size.

Why is enlarging the context window not simply a matter of allocating more memory?

The attention pattern is the square of the context size. Doubling the window quadruples that cost, which is why the limit that made early ChatGPT lose the thread was hard to lift.

Unembedding, and how many predictions get made

W_U maps the last vector to ~50,000 values, one per token. It has the same shape as W_E with rows and columns swapped, adding another ~617M parameters. Those raw unnormalised values are the logits; softmax turns them into a distribution.

Using only the final vector looks wasteful given thousands of context-rich vectors sitting in that layer. During training, every vector in the final layer simultaneously predicts what follows it, so one passage acts as many training examples. attention-transformers-step-by-step-deep also shows why masking is required: later tokens must not leak backwards into earlier predictions.

What are logits, and what turns them into a prediction?

The raw unnormalised values the unembedding matrix produces, one per vocabulary token. Softmax converts them into a probability distribution.

Every final-layer vector predicts what follows it. What does that buy, and what does it require?

It buys training efficiency — one passage becomes many training examples. It requires masking, because a prediction made at an early position must not see the later tokens that would give away its answer.

How many meanings can a space hold?

A space can hold more meanings than its dimension count; superposition explains how.
