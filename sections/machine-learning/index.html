Open questions

  • Does long context obviate retrieval, or relocate it? Primers • Retrieval Augmented Generation treats this as unresolved: longer windows change what needs retrieving and move the cost without removing it.
  • Why does RLHF beat SFT? RLHF: Reinforcement Learning from Human Feedback offers three hypotheses (diversity, negative feedback, hallucination) and, in its own words, no foolproof argument for any of them.
  • Does architectural design contradict the bitter lesson? Humans designed the Transformer, which delivered the largest recent gain. scaling-beats-knowledge-engineering offers a reconciliation: it encodes how to use compute, not what is true about language. This claim remains unsettled and worth testing against the next architecture.
  • Can an agent revise a plan after an unexpected error? LLM Powered Autonomous Agents names this as an open limitation; Primers • Agents adds protocols and frameworks around it without resolving it.
